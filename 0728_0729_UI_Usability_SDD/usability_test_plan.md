
# 可用性測試計畫 (Usability Test Plan)

### 1. 測試目的與受測對象

* **目的：** 評估團員點餐客製化、主揪一鍵結單防呆與對帳打勾之介面易用性與狀態可見性。
* **受測者：** 邀請 2 位未參與介面設計之同學 (標記為 **P01**, **P02**)，並進行去識別化隱私保護。

### 2. 測試任務 (Task Scenarios)

* **UT-01 (團員點餐)：** 「請進入房間並點一杯 50嵐 四季春，微冰微糖加珍珠，確認金額後送出。」
* **UT-02 (主揪結單鎖定)：** 「請以主揪身分發起一鍵結單，並確認團員端是否無法再送出訂單。」
* **UT-03 (對帳勾選)：** 「請檢視歸類後的店家總單，並在收到小明的飲料款項後標記為已付款。」

### 3. 主持人腳本 (中立指導)

* 「請依照你平時習慣操作，邊做邊說出你的想法（思考出聲法）。我不會進行提示，如果有介面不清楚的地方請直接提出。」
