
# 3 個核心任務流程 (Task Flows)

### 任務流程 1：團員點餐與客製化加價 (TF-01)

* **角色：** 一般團員
* **起點：** 點擊主揪分享之專屬網址 `/room/{uuid}` 進入房間。
* **主要步驟：** 進入房間 ➔ 輸入學號與暱稱 ➔ 選取飲料品項 (50嵐/可不可) ➔ 勾選甜度、冰塊與配料 (珍珠+10) ➔ 預覽小計金額 ➔ 點擊提交。
* **判斷/分支：**
  * 若房間 `is_closed == True` ➔ 前端按鈕停用 (Disabled)，提交時跳出 HTTP 403 鎖定提示。
  * 若學號空白 ➔ 欄位標示高亮紅框，阻止送出並保留已選配料。
* **可觀察終點：** 畫面渲染「點餐成功，小計 40 元」，下方點單清單即時出現該筆紀錄。

### 任務流程 2：主揪發起一鍵結單與鎖定 (TF-02)

* **角色：** 揪團主揪
* **起點：** 主揪於房間管理面板檢視當前點單。
* **主要步驟：** 點擊「一鍵結單」按鈕 ➔ 系統彈出確認對話框 ➔ 確認結單 ➔ 後端更新 `is_closed = True`。
* **可觀察終點：** 房間狀態標籤變更為「已結單 (Locked)」，團員端所有提交按鈕變灰停用。

### 任務流程 3：店家總單彙總與團員對帳勾選 (TF-03)

* **角色：** 揪團主揪
* **起點：** 結單後之主揪管理面板。
* **主要步驟：** 檢視系統自動歸類合併之「店家總單」➔ 打電話向店家訂餐 ➔ 飲料送達後依「團員對帳單」進行實體收現 ➔ 點擊勾選 `[x] 已付款`。
* **可觀察終點：** 團員清單之付款狀態即時更新為 `is_paid = True`。
