
# 介面狀態與錯誤回饋規格

| 狀態名稱                    | 觸發條件                          | 介面呈現細節                                       | 可用操作             | 恢復/離開機制      |
| :-------------------------- | :-------------------------------- | :------------------------------------------------- | :------------------- | :----------------- |
| **Normal**            | 房間開放中 (`is_closed==False`) | 點餐提交按鈕顯示綠色/藍色高亮                      | 填單、勾選加料、提交 | 點擊提交存檔       |
| **Disabled**          | 房間已結單 (`is_closed==True`)  | 按鈕變灰 (`disabled:bg-gray-400`)，顯示鎖頭 Icon | 無 (禁止發送 POST)   | 主揪解鎖或返回首頁 |
| **Error**             | 表單驗證失敗 (學號空白)           | 學號輸入框外框變紅，跳出 Toast 警示訊息            | 補填資料、重新提交   | 填寫學號後紅框消除 |
| **Permission Denied** | 結單後使用 API 強行點餐           | 後端回傳 403，彈出 Modal 提示「房間已結單」        | 點擊關閉對話框       | 點擊確認關閉 Modal |
