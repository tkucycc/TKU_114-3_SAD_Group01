
# 資料字典 (Data Dictionary)

| 編號            | 標準資料名稱   | 類型     | 定義與組成                                         | 格式 / 型態 / 允許值                         | 來源 → 去向     | 對應需求與規則 |
| :-------------- | :------------- | :------- | :------------------------------------------------- | :------------------------------------------- | :--------------- | :------------- |
| **DD-01** | 開團資訊       | 資料流   | 店家名稱 + 主揪暱稱                                | 文字 (String), 必填                          | E1 → 1.0        | FR-01          |
| **DD-02** | 房間連結資訊   | 資料流   | 專屬 URL 網址包含 UUID                             | `/room/{uuid}` 格式文字                    | 1.0 → E1        | FR-01          |
| **DD-03** | 點餐提交資料   | 資料流   | 學號 + 暱稱 + 飲品名稱 + 冰度 + 甜度 + [配料列表]  | JSON 格式，學號與暱稱必填                    | E2 → 2.0        | FR-02, BR-02   |
| **DD-04** | 個人點餐回應   | 資料流   | 提示訊息 + 個人小計金額                            | 小計為整數 (Integer, >=0)                    | 2.0 → E2        | FR-02, NFR-01  |
| **DD-05** | 結單指令       | 資料流   | 房間 UUID + 結單觸發訊號                           | 布林值 (Boolean),`is_closed=True`          | E1 → 3.0        | FR-03, BR-01   |
| **DD-06** | 店家彙總總單   | 資料流   | {飲品名稱 + 冰度 + 甜度 + 加料組合 + 合計杯數}     | 陣列物件，相同客製化自動合併歸類             | 4.0 → E1        | FR-04          |
| **DD-07** | 團員收款對帳單 | 資料流   | {學號 + 暱稱 + 點餐明細摘要 + 應付金額 + 付款狀態} | 付款狀態為布林值 (`is_paid`)               | 5.0 → E1        | FR-05, CON-01  |
| **DD-08** | 房間 UUID      | 資料項目 | 系統自動生成之唯一房間識別碼                       | 36 字元 UUID 字串                            | 1.0 → D1        | FR-01          |
| **DD-09** | 房間鎖定狀態   | 資料項目 | 標示房間是否已凍結修改權限                         | 布林值 (`True`: 已結單, `False`: 開放中) | D1               | FR-03, NFR-03  |
| **DD-10** | 個人小計金額   | 衍生資料 | 飲品基本價 + 項目配料加料金額總和                  | 整數 (Integer)，運算零浮點數誤差             | P2.0 計算存入 D2 | NFR-01, BR-03  |
