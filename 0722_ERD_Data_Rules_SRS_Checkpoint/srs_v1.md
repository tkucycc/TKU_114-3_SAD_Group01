
# 團訂飲料系統 軟體需求規格書 (SRS v1.0)

## 1. 文件資訊

* **專案名稱：** 團訂飲料系統
* **文件版本：** v1.0 (Baseline BL-SRS-01)
* **日期：** 115/07/22
* **作者與單位：** group01 陳昱丞 / 淡江大學資管系

## 2. 系統摘要與問題定義

本系統旨在解決班級、辦公室團體訂購飲料時，傳統 LINE 群組喊單格式混亂、主揪手動抄單耗時且容易遺漏，以及結單後對帳困難、主揪需自行代墊之痛點。

## 3. 系統範圍

* **範圍內 (In-Scope)：** 隨機 UUID 房間生成、團員自主點餐與客製化加價、主揪一鍵鎖定 (HTTP 403 後端防禦)、店家總單歸類合併、團員收款勾選清單。
* **範圍外 (Out-of-Scope)：** 線上第三方金流（LINE Pay 等）、飲料店 POS 機 API 連線、團員帳號註冊登入。

## 4. 核心需求與資料規格

* **功能性需求：** FR-01 (開團生成), FR-02 (選購點餐), FR-03 (一鍵鎖定), FR-04 (店家總單), FR-05 (收款清單)。
* **資料模型：** 核心由 `OrderSession`、`OrderDetail` 與 `MenuItem` 構成，已通過 1NF/2NF 正規化檢驗，並於 `main.py` 以 In-memory DB 完全實作。
