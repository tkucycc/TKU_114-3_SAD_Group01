
# 資料規則與基數檢核表 (Data Rule & Cardinality Check)

| 檢核項目                                         | 設定規格                     | 業務規則依據 (BR)                                  | 檢查結果       |
| :----------------------------------------------- | :--------------------------- | :------------------------------------------------- | :------------- |
| **OrderSession -> OrderDetail 基數**       | `1..1` 對 `0..*`         | BR-01 (開團初期可無點單，結單時可擁有多筆)         | **符合** |
| **OrderDetail -> OrderSession 參照完整性** | `1..1` (必填 FK)           | BR-REG-01 (點單不可為孤兒資料，必須存在對應房間)   | **符合** |
| **學號唯一限制 (Unique Constraint)**       | `UNIQUE(room_id, user_id)` | BR-REG-02 (同一房間內同一學號覆蓋點單，不重複建檔) | **符合** |
| **小計金額計價限制**                       | Integer,`>= 0`             | BR-03, NFR-01 (底價與加價運算零浮點數累積誤差)     | **符合** |
